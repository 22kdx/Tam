# حالة التنفيذ

## مكتمل
- مخطط العملات والصناديق والحركات والإعدادات.
- مصادقة API وربط الشركة والمستخدم.
- قراءة وإنشاء العملات والصناديق.
- حظر DELETE والإلغاء والعكس.

## متبقٍ
- الإيداع والسحب والتحويل والتصريف.
- الرسوم ومنع التكرار والتزامن.
- التقارير والتدقيق والصلاحيات.
- الواجهة العربية والاختبارات الكاملة.
